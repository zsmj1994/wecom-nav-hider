# 版本适配

内置适配：WXWork 5.0.12.6013，目标进程架构 `ia32`。v0.2.0 同时从 GitHub 适配目录获取已验证构建，目录保留 5.0.11.6029 和 5.0.12.6013。

## 发布适配配置

在 `adaptations.json` 的 `profiles` 添加已完成静态和运行时验证的构建，保留已有条目。每条包含下表及 `version`、`architecture`，另加 `verified: true`。目录协议为 `schema_version: 1` 和 `hook_api: 1`。`verified` 是维护者的验证声明，不是自动逆向结论；目录的信任来源是固定 GitHub 仓库的 HTTPS 内容，不接受任意下载源。

运行 `python -m unittest discover -s tests -v` 后提交并推送目录，即可由 v0.2.0 客户端在下次启动获取。不要在目录加入代码、脚本地址或未经验证的候选偏移。需要改变拦截逻辑时应升级 `hook_api` 和启动器，旧启动器拒绝未知协议。

远程目录无效或连接失败时使用已有缓存或内置配置。完全无法匹配时普通启动，不进行内存挂载。

`compatibility.json` 集中保存以下信息：

| 字段 | 用途 |
| --- | --- |
| `exe_sha256` | 确保执行文件与分析构建完全一致 |
| `dui_sha256` | 确保界面库布局与控件结构一致 |
| `assistant_predicate_rva` | 智能助理可见性判断函数，当前为 `0x256A700` |
| `navigation_return_rva` | 仅限导航调用的返回地址，当前为 `0x6CE5C54` |
| `control_name_offset` | 控件名称字段偏移，当前为 `0x78` |
| `control_parent_offset` | 父控件字段偏移，当前为 `0x50` |
| `navigation_container` | 将隐藏范围限制在导航容器内 |

地址为相对于模块加载基址的 RVA，运行时根据实际基址计算。JSON 中使用十进制数值。不要把首选映像虚拟地址直接当作 RVA。

5.0.12.6013 静态核对链路：导航布局 `weclaw_tab_op_layout` 的显示判断在 VA `0x70E5C4F` 调用 `0x38A4AD0`，后者跳转到 `0x296A700`。该函数读取 `enable_wecomagent`，默认值为 `0`，与 `1` 比较；导航返回 VA 为 `0x70E5C54`。首选映像基址为 `0x400000`。界面库的 `GetName` / `GetParent` 导出分别确认字段偏移仍为 `0x78` / `0x50`；两个 `SetVisible` 导出签名不变。

2026-10-13 启动阶段验证：13 次导航判断均从 `1` 覆盖为 `0`，随后智能助理普通/折叠布局及按钮共 52 次客户端 `SetVisible` 调用均为 `false`。截图检查和用户确认入口已消失。仅切换导航不一定执行此判断，升级后应退出企业微信，再通过新版启动器启动。其他可选项目未在本次升级中逐项重新验收。

智能助理的函数有其他调用者。仅匹配导航返回地址时覆盖返回值，避免影响其他业务调用。其他项目通过已命名控件的 `SetVisible` 调用隐藏，且检查父链属于导航容器；同时处理外层布局以减少空位。

适配新版本时需要重新核对函数、调用点、ABI、控件布局与名称。必须验证隐藏、恢复、刷新、进程退出和附加已有进程等行为。不能只修改哈希使检查通过。

路径探测与版本兼容是两件事：路径探测只找到候选安装；只有哈希通过才允许挂载。`DuiLib.dll` 从安装目录和直接子目录中匹配。

发布时只包含工具源代码及适配元数据，不分发目标程序、私有配置、账户目录、内存转储或带聊天内容的截图。
